4. 비즈니스 로직/트래킹/통계/파생 필드

- customer_journey_stage, progress_status 등
- 각 단계별 안내 메시지/상태값 관리

7. 주요 업무 플로우(비즈니스 로직) 요약

업무 항목핵심 플로우 요약관련 DB 필드구현 위치(코드)
수정회수 카운팅
(신규디자인만 카운터 전송)		 1. 신규 디자인 요청 시 revision 카운트 0으로 초기화
2. 고객이 수정 요청할 때마다 +1
3. (신규디자인일 때만) 카운터 안내 메시지 전송 		Design.revision1Count, revision2Count, revision3Count design-request.processor.ts, design.service.ts
결제 상태 안내
(성공/취소/실패/대기중)		 1. 결제 요청/완료/실패/취소 이벤트 발생
2. paymentStatus 필드 값 변경
3. 상태별 안내 메시지 전송 및 후속 처리(FLOW) 		Payment.paymentStatus payment-complete.processor.ts, payment.service.ts
오더시트 제출 후 자동 에이전시 연결 1. 오더시트(주문서) 제출 완료
2. ordersheet_complete_date 기록
3. 자동으로 담당자(에이전시) 할당 로직 실행(FLOW) 		OrderTracking.ordersheetCompleteDate, Customer.agentAssigned 등 order-tracking.service.ts, customer.service.ts

플로우 순서도(텍스트)

수정회수 카운팅
  [신규 디자인 요청] → revision1Count = 0
      ↓
  [수정 요청] → revision1Count += 1
      ↓
  [신규디자인일 때만] → 카운터 안내 메시지 전송
결제 상태 안내
  [결제 요청/완료/실패/취소 이벤트]
      ↓
  paymentStatus 값 변경
      ↓
  상태별 안내 메시지/후속 처리
오더시트 제출 후 자동 에이전시 연결
  [오더시트 제출 완료]
      ↓
  ordersheet_complete_date 기록
      ↓
  자동 담당자(에이전시) 할당 로직 실행
